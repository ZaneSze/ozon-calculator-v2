# OGL物流与新旧费率表兼容

更新日期：2026-10-16。

## 使用

- 在右侧物流区选择“第三方物流”或“官方 OGL 物流”；切换会清除当前物流商筛选和临时选中渠道。
- “数据 → 导入物流表（第三方 / OGL）”支持 CSV、XLSX、XLS。
- 旧第三方表继续使用字段识别和映射预览；OGL官方中英文表按表头自动识别。
- 上传第三方表只替换第三方渠道；上传OGL表只替换OGL渠道。同一文件包含两类工作表时分别更新。
- 中英文同内容工作表优先中文，避免重复计数；说明页和路由页不作为主费率表。
- 支持说明行、列顺序调整、发运方法合并单元格及工作表改名。费率、计费单位或必要限制无法识别时拒绝更新，保留现有数据。
- 导入数据存储在当前浏览器的IndexedDB中；刷新后恢复。不同浏览器、不同本地域名/端口的存储相互独立。

## 官方规则与内置数据

- [官方OGL费用规则](https://global-help.ozonru.cn/zh/commissions/ozon-fees/ogl-rates)，2026-10-16核对；页面显示更新时间为2026-09-09。
- [官方费率Excel（2026-08-24起生效）](https://cdn.ozone.ru/s3/ozon-disk-api/Partner_Delivery/OGL_ENG_CN_24_08_26_added_Pick-up_1786697358.xlsx)。原始文件保存在`public/data/OGL_2026-08-24.xlsx`，包含“CHINA OGL”和“中国 OGL”工作表。
- 内置12条渠道：上门取件、卖家自送各6个评分组。运输费为人民币固定费 + 人民币每克费 × 计费重量。
- 物流平台电子服务费：每票货值的2%，最低15卢布、最高200卢布，使用计算器当前结算汇率折算成人民币，与运输费分开列示并计入总成本。
- Extra Small、Budget、Small、Premium Small按实际重量；Big、Premium Big取实际重量与体积重较大值。官方“长×宽×高÷12”直接得到克；内部等价使用“÷12000×1000”。
- 支持货值口径切换、重量、尺寸、带电和液体限制。反推售价及定价矩阵会在同一发运方法下匹配目标售价对应的OGL评分组。
- 多件装按合并货件价值计算电子服务费保底/封顶，再按件分摊；实际合包尺寸、重量和评分组仍需按真实包裹确认。
- 退损继续采用用户所设概率与处理方式估算。官方页面未提供可统一套用的取消、退货逆向费用，因此未虚构统一逆向费率。

## 后续更新

直接上传新的官方物流Excel/CSV即可更新运输费和表中限制；无需修改代码或删除第三方渠道。旧版“固定费+每克费”合在同一列的第三方格式继续支持。

如果官方改变表头语义、币种、计费单位、费用模型或2%/15/200卢布的电子服务费规则，需要同步扩展解析器或费用模型。物流Excel不包含电子服务费规则，上传运输费表不会推断或改写该规则。内置费率日期指随软件提供的快照，导入记录显示实际文件名及导入时间。

## 验证

`npm test`同时运行历史解析回归和OGL专项验证，包括官方中英文表、CSV/XLS/XLSX、列重排、合并单元格、改名工作表、错误表保护、并存更新、体积重、服务费上下限、利润对账、跨组反推售价与汇率试算。

Windows本地运行沿用项目现有启动方式；此次更新无需新增服务、数据库或环境变量。
