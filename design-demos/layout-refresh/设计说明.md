# 旧版工作台：模块优先级和紧凑布局

设计范围：在用户熟悉的左参数、中结果、右物流与顶部设置骨架内，重新排模块和模块内部。现用工作台不改；用独立 HTML 看方向。

| 优先级 | 排版位置 | 理由 |
| --- | --- | --- |
| 高频 | 目标售价、目标利润率、首屏净利、六档报价、可用渠道和费用 | 改价、核对、决定能否发货应在同一屏完成。 |
| 按需 | 商品和采购细项、最高价格与划线价系数、各档完整报价、物流限制 | 留在原栏，摘要常显，展开后仍能看到已有细项。A 让常改的两个系数直接可见。 |
| 低频 | 竞品、阈值、促销、支付与税务、广告、汇率模拟、规则说明和不可用渠道 | 同区块内折叠，不另开页面。 |

- A 报价与利润同屏：左栏定价先行，两段系数直接可见；中栏先看费用，再读六档报价。
- B 商品参数先行：左栏先看包裹尺寸和重量；最高价格、划线价金额直接可见，系数一键展开。
- C 六档方案先行：中栏先扫六档报价对照，再看成本；左栏优先保留定价和采购摘要。
- 三版均把六张大卡压为对照表，原卡仍可展开；右栏把可用项与价格放在规则之前。手机有页内跳转，不新增子页。
- 样例源于项目已有 OGL 样例的脱机页面，三版用同一组数据。生产实施时恢复原有实时试算、复制、应用定价、导入和导出功能；第三方模式可默认展开物流商快捷筛选。原型只验证布局、折叠和页内定位。

[打开三版对比](index.html)。复现：在工作区运行 `python design-demos/layout-refresh/build.py`（依赖 Python Playwright 与 Windows Edge）。
