# 六个方向

六格初稿：[HTML](thumbs.html) · [截图](thumbs.png)。同样的价格与净利，不同的工作顺序。

| 方向 | 来源与借用 | 主角、骨架与形态由来 |
| --- | --- | --- |
| A 并排工作台（完整） | 最佳设计师路径：Edward Tufte 的同口径直接比较思路。以一条可核对的费用比例条代替装饰图，金额固定靠右。 | 实时利润与编辑区左右并排。唯一强色落在利润单上，因为试价要立刻对账。 |
| B 分步定价（完整） | 现实参照：[Linear 官方看板](https://linear.app/docs/board-layout) 的明确分组与当前状态；已看[参考截图](refs/linear-board.png)。 | 横向三步切换，活跃一步占主区域，底部持续保留当前报价。形态来自报价、发货、核算的顺序。 |
| C 渠道控制台（完整） | 最佳设计师路径：Khoi Vinh 的网格和信息位置思路。用左侧工作区索引与可横向扫读的表格稳定位置。 | 先比较发运方案，再核对右侧利润和下方报价；深绿只突出选中状态和净利。 |
| D 单页报表（备选） | 现实参照：同一 [Linear 界面](refs/linear-board.png) 中弱色分组条和一致的对齐。 | 三个价格平铺成单页报表，费用逐行核对，适合汇报。 |
| E 侧栏分区（备选） | 秒数轮盘：42 秒，东亚第 7 号「传统色与节气」，看过样张。取克制的低饱和配色和连续分区，不套用节气图形。 | 商品、报价、物流、结算四个视图分离，给长表更多宽度。 |
| F 情景对比（备选） | 秒数轮盘：42 秒，网页第 3 号「孟菲斯复古拼贴」，看过样张。仅借两块对照色和结构反差。 | 把两个售价方案并列，强调改价前后差值；缩略图仅把第二个金额作为待试算情景。 |

选 A、B、C 做完整版，因为它们分别把编辑、流程、物流设为第一阅读顺序。D 与 A 的结果优先相近，E 会增加切换，F 更像新增情景比较功能，因此暂留备选。
