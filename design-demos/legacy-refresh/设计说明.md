# 旧版工作台视觉优化初稿

用户范围：「只是对旧版的布局排版，按钮风格不统一，ui不美观有改进需求。帮我做一些设计，不要改变我原有的使用习惯。先给方案初稿」

以当前本地计算器在干净浏览器中的实际页面为底，捕获同一份 DOM 和 OGL 样例。设计稿没有接入业务写入和运算。

| 方向 | 视觉取舍 | 保留的使用方式 |
| --- | --- | --- |
| A 紧凑规整（推荐） | 统一按钮高度、圆角、边框和选中态；对齐表单与金额，推荐项单独着色 | 原来的三栏、字段顺序、区块折叠、滚动位置和入口 |
| B 清晰分区 | 给展开的参数组加浅底；突出净利与当前选择，增大栏间距 | 同 A，主要区别是留白和信息分区 |
| C 低彩专业 | 低饱和墨绿色、细线与轮廓选择态，减少色块对数字的干扰 | 同 A，继续维持较高的可见信息密度 |

不改变按钮的业务语义和位置；原有盈利红色、风险提示和物流类型的意义保持。并排展示是为了直接比较排版，三个方向有意共用旧版骨架。

- [对比总览](index.html)
- 截图：`screenshots/`，每版有首页、定价细节与手机首屏。
- 复现：在项目目录运行 `python design-demos/legacy-refresh/capture.py`，要求本地计算器在 3000 端口运行、已安装 Python Playwright 和 Edge。
- 真实页面代码要在选择方向之后修改。
